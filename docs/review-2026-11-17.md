## 4. UI and usability

- **P1 ✔ First run of the macOS app needs a local PostgreSQL it never mentions.** The app sets `KNODE_OS_DESKTOP=1`, which nothing reads, and the default database is PostgreSQL on 127.0.0.1:5432; the failure then shows as a 401. Default to PGlite for the desktop service and add a setup notice. (`macos/…/LocalServiceManager.swift:62`; `src/config.ts:1338`)
- **P1 Indexing is one blocking request with no progress and no cancel.** The web shows a toast that disappears after 60 s; the macOS client times out at 360 s while the server keeps going. Return 202 with an activity id, feed progress into Tasks, add an abort signal to `sync`. (`src/server/app.ts:2334`; `web/app.js:4582`)
- **P2 Provenance and maintenance are API/CLI only**: lineage, history, disputes, merges, forget, purge, rebuild, worksets and subscriptions have no screen; the macOS app also lacks Feishu import, the conversation catalog, feeds and research sources.
- **P2 Accessibility (web):** tree rows are spans with click and right-click only; the toast has no live region and is the only failure feedback; `outline: none` with no `:focus-visible`; 31 `confirm()`/`prompt()` dialogs. (`web/app.js:2319`; `web/index.html:952`; `web/style.css`)
- **P2 Language:** the web UI is English only; 24 macOS toasts bypass `L()`.
- **P3 Naming:** "index" / "ingest" / "sync"; "Processing" / `labeling` / `extract` / "tier 1". ARCHITECTURE.md §2 fixes the vocabulary; routes and commands should gain aliases to match (`/api/processing/*`).

## 5. Robustness

- **P2 ✔ Shutdown exits without closing workspaces**: the signal handler closes auth and the evaluation queue, then `process.exit(0)`; `WorkspaceContextRegistry.closeAll` is never called. (`src/server/serve.ts:232-236`)
- **P2 One sync mutex for the whole process**: a long sync in one workspace stalls sync and delete in all others. Key the chain by data directory. (`src/ingest/sync.ts:92`)
- **P2 Every workspace-open failure is answered 401**, with host and port text in the body. Use 503 with a reason. (`src/server/app.ts:637-640`)
- **P2 Completion and embedding calls have no timeout or cancel.** (`src/llm/providers/openai.ts:80`; `src/ingest/embeddings.ts:124`)
- **P2 `/api/grep` runs a caller's regular expression on the event loop**; a catastrophic pattern freezes every workspace. Run it in a worker with a deadline. (`src/fs/files.ts:397`)
- **P2 `saveConfig` is a non-atomic whole-file write of each process's copy**, so a CLI change can be erased by `serve`'s next save. (`src/config.ts:2212`)
- **P3** A fire-and-forget write can end `serve` (`src/work/translate.ts:472`, no `unhandledRejection` handler); about 20 routes have no error mapping and there is no `app.onError`.

## 6. Performance

- **P2** About 1 MB of static assets per load, uncompressed, uncached, read synchronously. Add compression, ETags and `defer`. (`src/server/app.ts:3857-3877`)
- **P2** `/api/stats` runs 13 `count(*)` scans and both clients poll it every 15 s, hidden or not. Cache and invalidate after sync. (`src/store/queries.ts:30-43`)
- **P2** Uploads are buffered whole and `/api` has no body limit. (`src/server/app.ts:1601`)
- **P3** Per-row queries in research lists; transcript tails read whole files on every poll; fixed caps without pagination; `/api/tree` walks the whole subtree by default.

## 7. Structure

Done in this pass: 49 unused exports, one dead module, and the locals and
imports they left, removed; identical helpers merged (`sha16`, `tokenMatches`,
the pack sampling helpers, the SQL lexer's patterns, `stringList`, `sleep`,
`likeEscape`, `quoteIdent`, `restoreArchived`); `noUnusedLocals` turned on so
the compiler keeps it that way.

Left as recommendations, because each changes behaviour or needs a model run to
verify:

1. **One post-extraction step** — done for `background.ts` and `labeling/followup.ts` (`afterExtraction`); `wiki/generate.ts` and `wiki/refine.ts` still keep their own lists of the same steps in "whole workspace" form.
2. **One leased-source base** for the five copies of lease bookkeeping in `labeling/scheduler.ts` and `work/{summarize,translate,judge,embed}.ts`; move the scheduler under `src/work`. Make the CLI pass a local worker over it, which removes `runTier1Pass` and the second summary and embedding drivers.
3. **One linked-source manager** behind folders, Feishu, conversations and repositories.
4. **One PostgreSQL lexer**: `store/catalog.ts` and `datasource/guard.ts` now share patterns but still each walk the tokens.
5. **Split the three large files along their existing banners**: `server/app.ts` (`createApp` is one 3,300-line closure) into `mountX(app, deps)` groups; `cli.ts` with a `withContext` wrapper and one service function per operation shared with its route; `config.ts` into types, defaults, load, migrate, routes, redact.
6. **Retrieval:** one "entities named in the query" (five exist), one Chinese tokeniser (three), one `RRF_K` and IDF.
7. **Evaluation:** retire reports recipe v2 once old runs no longer need reproducing; drop the pre-design-35 run layout and the `--slots` / `--offer-seconds` paths; share one renderer input for charts and mind maps across server, web and Swift.
8. Remove configuration read by nothing: `heat.coldThreshold`, `extraction.importance.skills`, `server.remote.evalOfferSeconds`.
